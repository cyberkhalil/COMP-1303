Course methodology: Phase 1 builds the theoretical foundations of operating systems with a short hands-on Linux touchpoint every week, grounding each concept in real commands and tools. Phase 2 shifts to deep practical mode, where students configure, deploy, and integrate real Linux services. Each week is delivered through a set of short video lessons, with a total weekly budget of 3 academic hours (135 minutes).

Phase 1 · OS Theory + Weekly Touch Labs
Phase 2 · Linux Practical (Deep Labs)

Phase 1 · Operating Systems Theory

Weeks 1 – 8 · Core OS concepts + a short Linux touchpoint every week
Week 1 Introduction to Operating Systems Theory + Touch Lab Lecture 1
OSTEP Intro · Silberschatz Ch 1–2

Learning Outcomes

  • Define the role and main components of an operating system
  • Differentiate user mode vs. kernel mode
  • Understand system calls, interrupts, and traps
  • Describe kernel structures (monolithic, microkernel, hybrid)

First Contact with Linux

  • Terminal, shell, and man pages
  • Navigating the file system: ls, cd, pwd
  • Understanding the FHS directory layout
Touch Lab: Set up the course VM (Ubuntu Desktop), open the terminal, and run your first commands — man, ls, cd, pwd, uname -a.
Week 2 Processes & Process Management Theory + Touch Lab Lecture 2
OSTEP Processes · Silberschatz Ch 3

Learning Outcomes

  • Explain process states, PCB, and context switching
  • Understand fork(), exec(), wait()
  • Describe the basics of inter-process communication (IPC)
  • Distinguish between process and program

Linux Commands Preview

  • ps, top, htop
  • kill, jobs, fg, bg
  • Exploring /proc/<pid>
Touch Lab: Write a short C program using fork(), observe the parent/child relationship with pstree, and inspect the process via /proc.
Week 3 Threads & Multithreading Theory + Touch Lab Lecture 3
OSTEP Threads · Silberschatz Ch 4

Learning Outcomes

  • Differentiate process vs. thread clearly
  • Explain thread models (1:1, N:1, M:N)
  • Understand thread benefits and overheads
  • Get introduced to race conditions

Linux Commands Preview

  • ps -eLf to view threads (LWPs)
  • Inspect /proc/<pid>/task
  • Basic pthread program in C
Touch Lab: Compile a program using pthread_create, run it, and use ps -eLf to observe the lightweight processes.
Week 4 Synchronization & Concurrency Theory + Touch Lab Lecture 4
OSTEP Locks · Semaphores · CV · Silberschatz Ch 5–6

Learning Outcomes

  • Identify race conditions and critical sections
  • Use mutexes, semaphores, and condition variables
  • Solve Producer–Consumer and Reader–Writer problems
  • Understand monitors in modern languages

Hands-on Concepts

  • Write multi-threaded code with pthread_mutex
  • Use sem_wait / sem_post
  • Debug with valgrind --tool=helgrind
Touch Lab: Implement a minimal Producer–Consumer using pthread mutex and condition variables, then run it under Helgrind.
Week 5 CPU Scheduling Theory + Touch Lab Lecture 5
OSTEP Scheduling · Silberschatz Ch 5

Learning Outcomes

  • Scheduling criteria: turnaround, waiting, response time
  • FCFS, SJF, SRTF, Round Robin, Priority
  • Multilevel Feedback Queues
  • Introduction to the Linux CFS scheduler

Analysis Concepts

  • Compute average waiting time per algorithm
  • Compare preemptive vs non-preemptive
  • Observe priorities via nice and chrt
Touch Lab: Launch CPU-intensive processes with different nice values and use top to observe how the scheduler allocates CPU time.
Week 6 Deadlocks Theory + Touch Lab Lecture 6
OSTEP Deadlock · Silberschatz Ch 7

Learning Outcomes

  • Coffman's four necessary conditions
  • Prevention, avoidance, detection, recovery
  • Banker's Algorithm (avoidance)
  • Resource allocation graphs

Applied Concepts

  • Deadlocks in database transaction systems
  • Diagnosing deadlocks in multi-threaded code
  • Using pstack / gdb to inspect threads
Touch Lab: Trace Banker's Algorithm step-by-step on a small resource allocation scenario using a Python or Bash script.
Week 7 Memory Management & Virtual Memory Theory + Touch Lab Lecture 7
OSTEP VM · Silberschatz Ch 8–9

Learning Outcomes

  • Contiguous allocation, paging, segmentation
  • TLB, page tables, multi-level paging
  • Demand paging & page replacement (FIFO, LRU, Optimal)
  • Thrashing and the working-set model

Linux Tools Preview

  • free, vmstat, memory view in top
  • Reading /proc/meminfo
  • Swap usage and swapon
Touch Lab: Inspect live memory usage with free and vmstat, and simulate FIFO/LRU page replacement on a reference string.
Week 8 File Systems, I/O & Midterm Exam Exam Midterm
OSTEP File Systems · Silberschatz Ch 10–11

Learning Outcomes

  • File abstraction: attributes, operations, directories
  • Allocation methods: contiguous, linked, indexed
  • Journaling & RAID levels (0, 1, 5, 10)
  • Disk scheduling: FCFS, SSTF, SCAN, C-SCAN

Midterm (20%)

  • Covers Weeks 1–7 material
  • Mixed MC, short answer, and problem-solving
  • 90-minute exam
Touch Lab: Explore the file system with df, mount, ls -i, and inspect inode structure before starting the midterm.

Phase 2 · Linux Practical

Weeks 9 – 14 · Six intensive weeks of hands-on Linux: shell, permissions, systemd, DNS, HTTP, MariaDB — ending with an integrated services lab
Week 9 Linux Shell, Users, Permissions & systemd Deep Lab Lecture 9
The Linux Command Line · How Linux Works

Learning Outcomes

  • Navigate the FHS directory tree confidently
  • Use pipes, redirection, and text tools: grep, sed, awk
  • Manage users and groups: useradd, usermod, groupadd
  • Change passwords: passwd; switch identity: su, sudo
  • Manage services with systemctl and journalctl

File Permissions

  • chmod in symbolic and numeric form
  • chown, chgrp, and umask
  • Understanding r/w/x for owner, group, and others
  • Awareness of setuid, setgid, and sticky bits
Deep Lab: Build a multi-user environment, change passwords, manage services, and enforce permission rules on shared directories.
Week 10 Packages, Networking Basics & DHCP Fundamentals Deep Lab Lecture 10
How Linux Works · Kea DHCP docs · UNIX/Linux SysAdmin Handbook

Learning Outcomes

  • Install and update packages with apt / dnf
  • Understand systemd unit files and service dependencies
  • Read IP addresses, subnet masks, and gateways
  • Use ip, ss, ping, traceroute

DHCP Fundamentals

  • The DORA process: Discover, Offer, Request, Ack
  • Leases, scopes, and standard options
  • Static reservations by MAC address
  • Where DHCP fits in a small lab network
Deep Lab: Configure a lightweight DHCP setup on the lab network to hand out addresses, and verify clients with ip and lease logs.
Week 11 DNS – Domain Name System Deep Lab Lecture 11
DNS and BIND (5th Ed.) · BIND 9 docs

Learning Outcomes

  • DNS hierarchy: root, TLD, authoritative servers
  • Resource records: A, AAAA, CNAME, MX, NS, PTR
  • Forward zones, reverse zones, and zone files
  • Caching, forwarding, and iterative queries

Hands-on BIND9

  • Install and configure BIND9 or dnsmasq
  • Create a master zone file for a lab domain
  • Verify with dig, nslookup, host
Deep Lab: Deploy a BIND9 server for lab.local with A, CNAME, and MX records, then test resolution from a client.
Week 12 HTTP – Web Service with Nginx Deep Lab Lecture 12
HTTP: The Definitive Guide · Nginx docs

Learning Outcomes

  • HTTP methods, status codes, and headers
  • Persistent vs non-persistent connections
  • Virtual hosts and document roots
  • Basic reverse proxy configuration

Hands-on Nginx

  • Serve a static site with Nginx
  • Configure two virtual hosts on one server
  • Reverse proxy to a simple backend
  • Read access and error logs
Deep Lab: Deploy Nginx with two virtual hosts, configure a reverse proxy to a backend service, and inspect logs.
Week 13 MariaDB – Database Service Deep Lab Lecture 13
MariaDB official documentation

Learning Outcomes

  • Understand the role of relational databases in a Linux stack
  • Install and start MariaDB with systemctl
  • Create databases, users, and grant privileges
  • Perform basic SQL: CREATE, INSERT, SELECT
  • Backup and restore with mysqldump

Administration Practice

  • Secure the installation with mariadb-secure-installation
  • Configure remote access per user and host
  • Inspect the server status and running queries
  • Verify data with a small client script
Deep Lab: Install MariaDB, create a database and user, grant least-privilege access, load sample data, and export a backup.
Week 14 Integrated Services Lab: DNS + HTTP + MariaDB Project Lab Integrated Lab
Guided integrated hands-on project

Learning Outcomes

  • Design a small end-to-end Linux service environment
  • Wire DNS → HTTP → MariaDB into one coherent stack
  • Diagnose service issues using logs and CLI tools
  • Document configurations and test results

Deliverables

  • Working DNS + Nginx + MariaDB setup on VMs
  • Screenshots and service test logs
  • Written report and/or short walkthrough video
Integrated Lab: Build a small network where DNS resolves an internal domain, Nginx serves a web app, and MariaDB stores its data — all on VMs.

Official Textbook & References

Main Theory

Operating System Concepts

Silberschatz, Galvin, Gagne — 10th/11th Edition. The official course textbook for the OS theory phase.

Modern & Free

Operating Systems: Three Easy Pieces (OSTEP)

Arpaci-Dusseau — free, modern, and excellent for building deep intuition on processes, threads, memory, and file systems.

Linux Basics

How Linux Works

Brian Ward — 3rd Edition. The go-to reference for understanding how Linux actually works under the hood.

Linux Commands

The Linux Command Line

William Shotts — 2nd Edition. A complete guide to shell usage, scripting, and everyday Linux tasks.

Sysadmin Reference

UNIX and Linux System Administration Handbook

Nemeth et al. — 5th Edition. A comprehensive administration reference used during the practical phase.

DNS

DNS and BIND

Cricket Liu & Paul Albitz — 5th Edition. Foundational DNS concepts, paired with modern BIND 9 official documentation.

HTTP

HTTP: The Definitive Guide

Gourley & Totty — complementary protocol depth, used alongside the Nginx official documentation.

Database

MariaDB Official Documentation

The primary reference for installing, configuring, and administering MariaDB during the database service week.
